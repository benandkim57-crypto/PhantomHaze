PhantomHaze — Security & Acceptable Use Policy
Last Updated: September 2026
1. Purpose
PhantomHaze is a privacy-focused web browser designed to help users protect the visibility of browser content from supported screen-capture, screenshot, screen-recording, and screen-sharing mechanisms.
PhantomHaze is provided as a browser and privacy tool. It does not control, monitor, endorse, or take responsibility for the websites, services, content, communications, downloads, uploads, or activities that users access through the browser.

Third-party websites operate independently and are subject to their own terms, privacy policies, security practices, and applicable laws.
4. Security Features
PhantomHaze may use operating-system security and privacy mechanisms intended to prevent or reduce the visibility of application content to supported screen-capture, screenshot, recording, or sharing mechanisms.
These features are intended as a privacy aid and are not a guarantee that content can never be captured.
Protection may vary depending on:
The operating system
Windows configuration
Capture or recording software
Remote-access software
Hardware
Virtual machines
Drivers
Browser or application behavior
Operating-system updates
Security vulnerabilities
Capture methods that operate outside supported Windows protection mechanisms
Users should not treat PhantomHaze as a guarantee against photography, screenshots from another device, malicious software, or other methods of obtaining information displayed on the screen.
5. Security Boundary
PhantomHaze's protection mechanisms are intended to protect content displayed within PhantomHaze itself.
They do not automatically protect:
Other applications
Other browser windows
The user's entire computer
Files stored elsewhere on the computer
Websites themselves
Information after it has been copied outside PhantomHaze
Users should avoid entering highly sensitive information into websites or services unless they trust those services and understand how the information will be handled.

9. No Guarantee of Security
PhantomHaze is provided as a security and privacy tool, but no software can guarantee complete security.
Users acknowledge that security protections can fail, be bypassed, become unavailable, or behave differently across systems and configurations.
PhantomHaze should therefore be considered one layer of a broader security strategy rather than a complete security solution.
10. Security Vulnerabilities
If a user discovers a potential security vulnerability in PhantomHaze, they are encouraged to report it responsibly to the developers rather than publicly disclosing exploitable details before a fix can be developed.
Security reports should include enough information for the developers to reproduce and investigate the issue, including:
PhantomHaze version
Windows version/build
Steps to reproduce the issue
Expected behavior
Actual behavior
Relevant logs or error messages
Proof-of-concept material where appropriate
Users should avoid including passwords, authentication tokens, private keys, personal information, or other sensitive data in security reports.

Users should keep PhantomHaze and their operating system reasonably up to date.
